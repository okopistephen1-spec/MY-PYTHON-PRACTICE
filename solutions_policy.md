# Solutions and Academic Honesty

This repository intentionally provides starter files and tasks rather than immediately showing every solution. The aim is to help you build problem-solving skills.

Suggested workflow:
1. Attempt the problem independently.
2. Read the relevant lesson.
3. Request a hint if stuck.
4. Run tests and debug.
5. Ask AI to mark your attempt.
6. Only look at a worked solution after making a genuine attempt.
7. Recreate the solution without looking and explain it.

When contributing solutions to a public version of this repository, explain the reasoning and include tests. Do not merely paste code.
