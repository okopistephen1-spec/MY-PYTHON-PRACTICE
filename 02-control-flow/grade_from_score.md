# Exercise: Grade From Score

Convert a score into a grade.

Return `A` for 70–100, `B` for 60–69, `C` for 50–59, `D` for 45–49, and `F` for below 45. Raise ValueError if score is below 0 or above 100.

## How to check
Run the matching test file with pytest. Your tests should pass when the function meets the requirements.
