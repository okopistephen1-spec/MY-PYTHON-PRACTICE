# Module 00 — Additional Exercises

Complete these after reading `README.md`. Write solutions in a separate file if you want to preserve your first attempt.

## Level 1 — Recall and explain
1. Explain the main concept from this module in your own words.
2. Create a tiny example that demonstrates it.
3. Predict the output of your example before running it.

## Level 2 — Guided practice
4. Recreate one worked example without looking at the lesson.
5. Change the input and explain how the output changes.
6. Write a function or short program that applies the concept to a new example.

## Level 3 — Independent problems
7. Solve a small problem using this module's concepts and at least one earlier concept.
8. Test a normal case, a boundary case, and an unusual case.
9. Add a docstring or comment explaining the purpose of your solution.

## Level 4 — Debugging
10. Write a version with one deliberate bug. Record the symptom, identify the cause, and correct it.
11. Ask an AI tutor to review your corrected attempt. Verify every claim.

## Level 5 — Challenge
12. Build a small feature related to one of the mini-projects. State its requirements first and test it.

## Written reflection
- Which exercise took the most thinking?
- What was your first incorrect assumption?
- What did the error or test result teach you?
- Could you solve the exercise again tomorrow without notes?
