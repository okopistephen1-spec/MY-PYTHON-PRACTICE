# Testing exercise

Create a function named `safe_divide(a, b)` that returns `a / b` when `b` is not zero and returns `None` when `b` is zero.

Write tests for:
- `safe_divide(12, 3)` returns `4`
- `safe_divide(5, 2)` returns `2.5`
- `safe_divide(12, 0)` returns `None`
- negative values
- floating-point inputs

Run the tests, then deliberately break the function to see whether the tests catch the mistake. Restore it afterward.
